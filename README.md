# 🖼️ Image Filter App – Beginner Python Mini Project

This project is a beginner-friendly **Image Filter App** built using Python. It applies visual filters to an image using the **Pillow** library and displays the original and processed images using **Matplotlib**. Designed for students learning about **Advanced Python Libraries**, this project is part of a Semester 4 curriculum under the topic: *Programming in Python – Unit 7*.

---

## 📌 About the Project

This mini project demonstrates how to manipulate and visualize images using Python’s advanced libraries. It applies basic filters like grayscale, blur, and edge detection, allowing students to learn image processing fundamentals in a fun and visual way.

The application is simple yet scalable and helps reinforce concepts of Python functions, external libraries, and data visualization.

## 🚀 Features

🎨 **Apply Image Filters**: Grayscale, Blur, and Edge Detection
