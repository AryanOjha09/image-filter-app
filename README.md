# 🖼️ Image Filter App – Mini Project (Using Pillow & Matplotlib)

This is a beginner-friendly mini project created using Python. The app loads an image, applies multiple filters using the **Pillow** library, and visually displays the results using **Matplotlib**. It's designed for educational purposes under the topic **Advanced Libraries in Python**.

---

## 📌 Features

✅ Load an image using Python  
✅ Apply the following filters:
- Grayscale
- Blur
- Edge Detection

✅ Display original and filtered images side-by-side using Matplotlib  
✅ Simple, clean, and easy-to-understand code  
✅ Ideal for students learning Python image processing  

---

## 🛠️ Technologies & Libraries Used

- **Python 3.x**
- **Pillow** – for image handling and filters
- **Matplotlib** – for displaying image output
